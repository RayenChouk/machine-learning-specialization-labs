# Machine Learning Specialization Labs

Programming labs and assignments completed as part of **Andrew Ng's Machine Learning Specialization**.

## 📚 Contents

The repository covers the practical implementation of concepts including:

- Linear and logistic regression
- Gradient descent and regularization
- Classification
- Neural networks and backpropagation
- Decision trees and ensemble methods
- Unsupervised learning
- Recommender systems
- Reinforcement learning

## 🛠️ Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook
